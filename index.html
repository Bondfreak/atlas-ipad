Søvandsfilter og søvandspumpe

EPF-0032 · KO-D4-0006

Funktion

Den motordrevne pumpe suger søvand gennem indtaget og filteret og sender det videre gennem motorens kølere og varmeveksler.

Kølevandets vej

Indtag → filter → pumpe → kølere → varmeveksler → udstødning → overbord

Normal funktion

Stabil motortemperatur, synligt overbordsvand, ingen lækage eller saltspor og ingen unormal lyd.

Ved problemer

Kontrollér først søventil, filter og udløbsvand. Undersøg derefter impeller, pumpe, slanger og kølere.

Ingen kølevandsstrøm eller temperaturalarm: reducér belastningen og stop motoren sikkert.
